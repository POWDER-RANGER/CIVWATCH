# Contributing

This project is in early development. External contributions are limited at this stage.

## Setup

1. Fork and clone the repository
2. Install dependencies: `npm install && pip install -r requirements.txt`
3. Run tests: `npm test && pytest`
4. Start development environment: `docker-compose up`

## Code Standards

- ESLint + Prettier for JavaScript/TypeScript
- PEP 8 for Python
- Run linters before committing: `npm run lint`

## Commits

Use conventional commits format:

```
feat(component): add feature
fix(component): fix bug
docs: update documentation
```

## Pull Requests

1. Create a feature branch
2. Make changes with tests
3. Submit PR with clear description
4. Address review feedback

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for community guidelines.
