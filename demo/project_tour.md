# Demo Usage

## Data Ingestion Demo

The `data_ingestion_demo.py` script demonstrates basic data analysis capabilities.

### Requirements

```bash
pip install -r requirements.txt
```

### Run

```bash
python data_ingestion_demo.py
```

This generates sample civic data and produces visualization outputs.

## Setup

```bash
git clone https://github.com/POWDER-RANGER/CIVWATCH.git
cd CIVWATCH
npm install
pip install -r requirements.txt
docker-compose up
```

## Current Features

- Sample data generation
- Basic analytics (sentiment, metrics)
- Visualization with matplotlib
