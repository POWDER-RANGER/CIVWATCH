# Recognition

We value all contributors to CIVWATCH. This document explains how we acknowledge contributions.

## Forms of Recognition
- Contributors.md: add your name and profile link via PR
- Release notes: shout-outs for significant features/fixes
- Badges: “First PR”, “Bug Hunter”, “Docs Champion” (digital badges in README)
- Maintainer nomination: outstanding contributors may be invited to maintainership

## Eligibility
- Any merged PR or triaged issue qualifies
- Community leadership (reviews, support) is considered

## Process
- Automated weekly script aggregates contributions for the past week (planned)
- Maintainers curate notable highlights for release notes and Discord announcements

## Swag (Future)
- Stickers/shirts for major milestones, subject to budget and availability

## Code of Conduct
Recognition is contingent on upholding the project’s CODE_OF_CONDUCT.md.
