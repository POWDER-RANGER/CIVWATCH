# Frequently Asked Questions

Below are answers to common questions about CIVWATCH.

## What is CIVWATCH?
A civic transparency platform under active development. See docs/README.md for scope and roadmap.

## Is there a working app today?
Not yet. The repository is in early development; implementation begins with Phase 1.

## How do I get support?
See docs/support.md for channels and response expectations.

## How can I contribute?
Read CONTRIBUTING.md, pick an issue, and submit a PR.

## What tech stack will CIVWATCH use?
Planned: React/TypeScript frontend, Node/Express API, Python ML service, PostgreSQL, Docker/Kubernetes.

## Is there an API?
API design is documented in docs/api.md; endpoints will be implemented during MVP.

## What about privacy and data usage?
Architecture.md outlines privacy-by-design principles. No real PII should be uploaded to this repository.

## What’s the license?
MIT. See LICENSE.

## Where can I discuss ideas?
Join the Discord or open a GitHub discussion/issue.

## How do I report a security issue?
Until SECURITY.md exists, email security@civwatch.org or open a private security advisory.
