# Support

If you need help with CIVWATCH, use these channels:

## Channels
- Discord: https://discord.gg/civwatch (fastest for chat)
- GitHub Issues: https://github.com/POWDER-RANGER/CIVWATCH/issues (bugs, feature requests)
- Email: support@civwatch.org (account, legal, private matters)

## Response Times (Target)
- Critical incidents: same business day
- General questions: 2-3 business days
- Feature requests: triaged weekly

## Before You Ask
- Search open/closed issues and docs/FAQ
- Include reproduction steps, logs, versions, and screenshots where applicable

## Security
- Report vulnerabilities to security@civwatch.org or via GitHub Security Advisories. Do not post exploits publicly.

## Code of Conduct
All interactions are governed by CODE_OF_CONDUCT.md. Be respectful and constructive.
