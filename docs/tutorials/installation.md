# Installation

Prerequisites:
- Node.js 20+, npm 10+
- Python 3.11+
- Docker and Docker Compose

Steps:
1. Clone the repo
2. Install dependencies (`npm install` at root or per package)
3. Copy .env.example to .env and fill required values
4. Start services: `docker compose up -d`
5. Run dev servers: `npm run dev`

Troubleshooting:
- See docs/support.md or open an issue with logs.
