# Maintainers

Ecosystem-level maintainer record for the CIVWATCH / CIVINT repositories under the [POWDER-RANGER](https://github.com/POWDER-RANGER) GitHub account.

## Current Status

This is a single-maintainer, single-operator project. There are no external maintainers, no security team, and no organization behind it. All development, review, release, and security handling is performed by one person.
